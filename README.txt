NBA2K Universal Converter APK project - v0.1

This is the Android APK source/build project.
It is NOT a precompiled APK.

Build on Linux/WSL with:
  pip install buildozer
  buildozer android debug

The current UI is the foundation only; the proprietary NBA 2K model
decoder/writer still has to be implemented before this can perform a
real 2K14 -> 2K20 Mobile conversion.
